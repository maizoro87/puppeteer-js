RAILWAY DEPLOYMENT - QUICK START GUIDE
=================================================================

Your MCP server is ready to deploy! Here's what to do:

OPTION 1: CREATE NEW RAILWAY PROJECT (RECOMMENDED)
---------------------------------------------------

1. Go to: https://railway.app/dashboard

2. Create GitHub Repo for MCP server:
   - Download: /home/runner/workspace/playwright-mcp-deploy.tar.gz
   - Extract on your machine
   - Create repo: https://github.com/new
   - Name: playwright-mcp-http
   - Push the extracted code

3. Deploy on Railway:
   - Click "New Project"
   - Select "Deploy from GitHub repo"  
   - Choose "playwright-mcp-http"
   - Railway auto-detects Dockerfile
   - Build completes in ~2-3 minutes
   - Click "Generate Domain" for public URL

4. Test your deployment:
   curl https://YOUR-URL.railway.app/health

   Should return:
   {"status":"ok","service":"playwright-mcp","timestamp":"..."}


OPTION 2: REPLACE EXISTING DEPLOYMENT
--------------------------------------

If you have access to the old Railway project:

1. Go to: https://railway.app/project/YOUR_PROJECT_ID

2. Settings → Delete Service (delete old one)

3. Create New Service:
   - Same project
   - Deploy from GitHub (use new repo from Option 1)
   - Railway generates new URL

4. Update Innovation Hub code with new URL
